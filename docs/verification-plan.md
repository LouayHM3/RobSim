# Verification plan

Unit tests cover PID saturation/anti-windup, actuator limits, sensor behavior,
and deterministic execution. Integration tests exercise closed-loop tracking,
dropout, and safe-state transitions. Scenario verification executes every YAML
file and writes a result bundle.

The primary quantitative measures are RMSE, maximum absolute error, final error,
overshoot, settling/rise time, control effort, maximum velocity, measurement age,
fault count, safe-state time, and diagnostic count. A scenario passes only when
its YAML acceptance criteria are met; fault scenarios explicitly require safe-state
activation where appropriate. Results in `results/` are generated by the CLI and
must not be treated as clinical or hardware validation evidence.
